# DoSJE Sentinel — Prototype

Risk-based monitoring & inspection platform for govt welfare schemes.
React + Vite + TailwindCSS + lucide-react + Framer Motion. All data is mock/dummy — no backend.

## Run locally
```
npm install
npm run dev
```
Open the printed localhost URL (usually http://localhost:5173).

## Build for deployment
```
npm run build
```
Output goes to `dist/`.
